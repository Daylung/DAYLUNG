# kompas — интерфейс рекомендатора цифровых сервисов

Только визуальная часть и структура. Никакого AI, авторизации, оплаты и партнёрских ссылок — их место помечено в коде.

```
index.html    разметка
styles.css    визуальная система
script.js     поведение интерфейса
screens/      скриншоты для проверки
```

Открывается двойным кликом по `index.html`.

## Что реализовано

**Первый экран**
- Логотип-компас (SVG), горизонтальная навигация, переключатель темы, кнопка-CTA
- Заголовок «Не знаешь, какой сервис выбрать?» — 69px на десктопе, tracking −0.042em
- Поисковая строка с плейсхолдером «Например: какой VPN лучше для iPhone и стриминга»
- Чипы с примерами запросов — по клику подставляют текст в поле
- Метрики-подложка: 4 цифры в одной рамке, разделённые линиями сетки
- Фон: сетка 72×72px, гаснущая маской, плюс фиолетовое свечение за заголовком

**Остальные секции**
- Категории: 4 карточки (AI, VPN, хостинг, бизнес) с иконками, счётчиками и наклоном стрелки при наведении
- Три шага — единый блок с внутренними разделителями, без «карточек в вакууме»
- Пример подбора: запрос пользователя → ответ с тремя карточками сервисов, процент совпадения, полосы характеристик, плюсы зелёным / минусы жёлтым
- Преимущества — четыре принципа
- CTA-полоса с повторной формой
- Футер: бренд, три колонки ссылок, юридическая строка

**Технически**
- Токены в `:root`, полная светлая тема через `[data-theme="light"]`
- Тёмная тема по умолчанию, выбор запоминается в `localStorage`
- Все контрасты текста ≥ 5.4:1 (WCAG AA)
- Нет горизонтального переполнения на 390 / 768 / 1024 / 1440
- Появление блоков через `IntersectionObserver`, `prefers-reduced-motion` учтён
- Фокус-стили, skip-link, `aria-expanded` на бургере, скрытые подписи для полей

## Где что менять

**Акцентный цвет** — две строки в начале `styles.css`:

```css
--acc:   #7a5cff;
--acc-2: #a78bfa;
```

**Логотип.** SVG прямо в разметке, дважды: в шапке и в футере. Градиент задан в `<defs>` с `id="bg1"` — при замене на свою картинку удалите блок `<defs>`.

**Тексты и цифры.** Всё в `index.html`. Счётчики сервисов в категориях — `.cat__meta`, метрики — в `dl.metrics`, проценты совпадения — `.svc__match b`, полосы — инлайн-стиль `style="--v:96%"`.

**Порядок секций** — просто переставьте `<section>` в `index.html`. Навигация ссылается на `id`, ничего не сломается.

## Точка подключения логики

В `script.js`, функция `handleAsk`, помечена `TODO`. Сейчас она проверяет длину ввода и показывает тост. Реальная отправка — там же:

```js
fetch('/api/recommend', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ query: q })
})
  .then(r => r.json())
  .then(data => renderResults(data));
```

Блок `.demo` в секции `#example` — готовый макет того, как должен выглядеть ответ. Его разметку можно превратить в шаблон для `renderResults`.

## Что сознательно не сделано

- Категории и карточки сервисов кликаются в тост, а не ведут на страницы
- «Подробнее» в карточках — не ссылка, потому что партнёрских переходов пока нет
- Все сервисы в примере вымышленные (Aurora, Tunnel One, Northline), данные помечены как демонстрационные
- Формы никуда не отправляются
